# GenSim task catalog

当前 checkout 注册了 **211 个 task 标识**：基础任务及变体 46 个（对应 41 个类），生成任务 165 个。

任务说明取自源码类的 docstring，可能与 reset/goal 的实际实现存在差异；注册成功不代表专家采集一定成功。max_steps 是每个 episode 的动作次数上限，并非任务必需步骤数。

生成命令：用 `.venv/bin/python` 导入 `cliport.tasks.names` 和 `cliport.generated_tasks.new_names`，通过 `inspect` 获取源码位置和类说明；只实例化任务读取 max_steps，不创建仿真环境。

## 运行方法

在仓库根目录执行：

```sh
export GENSIM_ROOT="$PWD"
uv run python cliport/demos.py n=1 task=stack-block-pyramid-seq mode=test disp=True data_dir="$PWD/data/pyramid-preview"
```

替换 task 的值即可切换任务。已存在的演示计入 n，必要时换 data_dir。标识区分大小写，尤其是 `Four-corner-pyramid-challenge`。Google objects 系列需要额外的 google 资产，当前安装未验证它们。
